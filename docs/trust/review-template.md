# Security review record template

Copy this into a versioned record after performing a review. Empty fields are
uncompleted work, not approval. This template is not a completed human review.

| Field | Record |
|---|---|
| Reviewer / organisation / relevant competence | Not recorded |
| Relationship to project; independent or maintainer review | Not recorded |
| Review date and full commit / tag / image digest | Not recorded |
| In-scope components and explicit exclusions | Not recorded |
| Deployment, configuration, threat assumptions | Not recorded |
| Manual methods and test cases; tool versions and commands | Not recorded |
| Evidence links; actual outcomes including failures | Not recorded |
| Findings, severity rationale, affected versions, remediation | Not recorded |
| Residual risks, exceptions, owner and expiry | Not recorded |
| Retest scope and result | Not recorded |
| Release decision and responsible human approval | **Not approved** |

Do not put secrets, customer logs or embargoed exploit details in a public record.
Publish a redacted summary and retain restricted evidence through an appropriate
private channel. An AI-generated signature or checked checkbox is not human approval.
